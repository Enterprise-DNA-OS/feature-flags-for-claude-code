# Add a report

Read the existing SQL views and views.json. Convert the requested business question into a SELECT query. Use established record meanings, label unknown values and exclude retired flags through flag_inventory. Add a named entry to views.json, then run npm run view and inspect its HTML. Test an empty result and a record with special characters. Do not create a web application or alter records. Report the local output path and the date of the data.

Arguments: $ARGUMENTS
